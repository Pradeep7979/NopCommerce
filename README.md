# nopCommerce Automation Framework

End-to-end UI automation framework for nopCommerce built using Selenium WebDriver, Java, TestNG, Maven, and Extent Reports.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- WebDriverManager
- Extent Reports

## Framework Highlights
- Page Object Model design
- Cross-browser setup
- TestNG suite execution
- JSON-driven test data
- Extent Reports integration
- Screenshot capture on failure
- Reusable base test and listeners

## Test Scenarios
- User registration
- Invalid login validation
- Gift card purchase flow
- Build your own computer flow
- MacBook Pro product flow
- HTC smartphone flow

## How to Run
```bash
mvn test
